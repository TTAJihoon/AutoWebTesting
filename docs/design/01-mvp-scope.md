# 01. MVP 범위

## MVP 방향

MVP는 단일 화면 자동화가 아니라 **URL 기반 AI 탐색형 CRUD 테스트 자동화**를 목표로 한다.

```text
URL + 계정 정보 + 시험 방법 설명
→ AI가 웹앱 탐색
→ 주요 기능과 CRUD 흐름 후보 발견
→ PageState / PageFlow / TestCase / ExecutionPlan 자동 생성
→ 사람이 검토 및 승인
→ Playwright 반복 실행
→ 증적과 보고서 생성
```

## MVP에 포함하는 범위

| 구분 | 포함 여부 | 설명 |
|---|---:|---|
| Windows 11 데스크톱 앱 | 포함 | Electron + React + TypeScript 기반 |
| AI 탐색 모드 | 포함 | URL을 기준으로 화면을 관찰하며 기능/흐름 후보 생성 |
| GPT Web Import Mode | 포함 | 초기 비용 절감용 운용 방식 |
| API Mode / 내부 AI 서버 | 구조 고려 | 궁극적 목표이나 구현은 단계화 |
| 기능목록 Excel | 선택 | 있으면 테스트 범위 보강에 사용 |
| 제품 매뉴얼 | 선택 | 있으면 기능 이해 보강에 사용 |
| 웹 제품 형상 탐색 | 포함 | DOM, 화면, 버튼, 입력칸, 테이블, 팝업 탐색 |
| 테스트케이스 자동 생성 | 포함 | 문서 + 제품 형상 기반 TC 생성 |
| 실행계획 자동 생성 | 포함 | 승인된 TC와 탐색 결과 기반 생성 |
| CRUD 자동화 | 포함 | 등록, 조회, 수정, 삭제/비활성화 흐름 |
| 실행 이벤트 스트림 | 포함 | 실행 중 진행률과 단계별 상태 표시 |
| HTML/Excel/ZIP 보고서 | 포함 | 결과와 증적 산출 |

## MVP에서 제외하거나 제한하는 범위

| 항목 | 처리 방식 |
|---|---|
| CAPTCHA | 자동화 제외 |
| 2단계 인증 | 자동화 제외 또는 사전 로그인 세션 사용 |
| 공동인증서/보안모듈 | 자동화 제외 |
| 실제 결제 | 기본 차단 |
| SMS/메일/푸시 등 외부 발송 | HIGH, 명시 승인 후 제한 실행 |
| 외부기관 제출 | 기본 차단 또는 HIGH |
| 권한/보안설정 변경 | HIGH 또는 PROHIBITED |
| 운영 데이터 직접 삭제 | 기본 차단 |
| 자동 생성 데이터 삭제 | HIGH, 명시 승인 후 제한 실행 |
| 복잡한 이미지/그래프 의미 검증 | 수동 확인 또는 이미지 보강 |
| 다운로드 파일 내부 내용 정밀 검증 | 후속 Phase |
| 병렬 브라우저 대량 실행 | 후속 Phase |

## CRUD 중심 커버리지 기준

CRUD 중심 자동화는 일반 업무용 웹 시스템에서 높은 비중을 차지한다. 다만 모든 품질 특성을 커버하지는 않는다.

| 제품 유형 | CRUD 중심 자동화 예상 커버리지 |
|---|---:|
| 단순 관리자/코드관리/게시판형 | 70~85% |
| 일반 업무관리/신청관리 시스템 | 50~70% |
| 승인·권한·상태전환이 많은 시스템 | 40~60% |
| 대시보드/통계/시각화 중심 | 25~45% |
| 실시간/외부연계/보안 중심 | 20~40% |
