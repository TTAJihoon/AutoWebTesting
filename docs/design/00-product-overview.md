# 00. 제품 개요

## 제품명

**AutoWebTesting**

## 제품 목적

AutoWebTesting은 비개발자 테스터, QA 담당자, 시험 담당자가 URL과 시험 방법 설명을 입력하면 AI가 웹 제품을 탐색하고, 실제 제품 형상에 기반하여 테스트케이스와 실행계획 후보를 생성하며, Playwright로 자동 실행하고, 결과 보고서와 증적을 생성할 수 있도록 지원하는 Windows 11 데스크톱 앱이다.

## 핵심 차별점

AutoWebTesting은 기존 자동화 시험 도구처럼 사람이 테스트케이스와 화면 매핑을 모두 수동으로 작성한 뒤 실행만 자동화하는 도구가 아니다.

핵심 차별점은 다음이다.

```text
URL + 계정 정보 + 시험 방법 설명
→ AI가 웹앱 탐색
→ 주요 기능과 CRUD 흐름 후보 발견
→ PageState / PageFlow / TestCase / ExecutionPlan 자동 생성
→ 사람이 검토 및 승인
→ Playwright 반복 실행
→ 증적과 보고서 생성
```

## 핵심 사용자

- 소프트웨어 시험 담당자
- QA 담당자
- 웹 서비스 검수 담당자
- 개발 지식은 많지 않지만 테스트 시나리오와 업무 흐름을 이해하는 실무자

## 핵심 원칙

| 원칙 | 설명 |
|---|---|
| 로컬 우선 | 기본 실행은 사용자의 PC에서 수행한다. |
| AI 탐색 우선 | URL과 시험 의도를 바탕으로 AI가 주요 화면과 기능 후보를 탐색한다. |
| 사람 검토 | AI가 생성한 후보는 실행 전 사람이 검토하고 승인할 수 있어야 한다. |
| 안전 실행 | 리스크 정책을 통과한 실행계획만 Playwright로 실행한다. |
| 제한된 자동화 | AI가 만든 임의 코드를 실행하지 않고, 허용된 action만 실행한다. |
| 추적 가능성 | 제외, 거부, 실패, 수동처리 대상도 이력으로 보존한다. |
| 실무 재현성 | 실행 당시의 DOM, 실행계획, 테스트 데이터, 로그, 증적을 함께 보존한다. |

## 언어 작성 원칙

설명은 한글로 작성한다.  
타입명, 필드명, enum, 파일명은 영어를 유지한다.
