# ADR-002: Observation은 DOM 우선 + 선택적 이미지 보강으로 한다

## 상태

- status: accepted
- date: 2026-05-15

## 배경

AI 에이전트가 웹 화면을 이해할 때 스크린샷은 유용하다. 그러나 모든 화면에서 이미지를 LLM에 전달하면 비용, 속도, 보안, 재현성 문제가 발생한다.

## 선택지

### 선택지 A — DOM Summary만 사용

비용과 보안 측면에서는 유리하지만 아이콘 버튼, 모달, 그래프 등 시각 정보 판단이 어렵다.

### 선택지 B — 모든 Observation에 이미지 포함

화면 이해력은 높아지지만 비용과 민감정보 노출 위험이 커진다.

### 선택지 C — DOM 우선 + 선택적 이미지 보강

기본 판단은 DOM Summary로 수행하고, 필요한 경우 masked screenshot을 추가한다.

## 결정

선택지 C를 채택한다.

## 이유

텍스트 DOM은 구조화와 재현성에 강하고, 이미지는 화면 이해 보조에 강하다. 두 방식을 역할에 따라 나누는 것이 가장 안정적이다.

이미지는 다음 조건일 때만 사용한다.

- 아이콘 버튼이 많아 DOM 텍스트만으로 의미 파악이 어려운 경우
- 모달/팝업 위치 판단이 필요한 경우
- 차트/그래프/대시보드 화면
- DOM이 div 기반이라 테이블 구조 추출이 어려운 경우
- OCR이 필요한 이미지 텍스트가 있는 경우

이미지 전송 전에는 비밀번호, 토큰, 개인정보, 계정명, 금액 등을 마스킹한다.
